    Link your M-Pesa (Android)

    Your phone can send every M-Pesa SMS here automatically. This link is personal: anyone who has it can add transactions to your account, so keep it private.

    1. Install SMS to URL Forwarder (free, Play Store) or any app that forwards SMS to a URL.
    2. Add a rule: sender MPESA, method POST, URL = the link above. The default JSON template works.
    3. In Android settings, set the app's battery usage to Unrestricted.
    4. Buy KES 10 of airtime to test. It should appear under Transactions within seconds.
